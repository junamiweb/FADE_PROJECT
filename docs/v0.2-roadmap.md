# FADE v0.2 — Roadmap

מסמך תכנון. מבוסס על:
- הדרישה המקורית ל-v0.1
- החזון הרחב (צפייה, ניתוח היסטורי, שינויים משמעותיים, חיזוי עם %)
- תוצאות ההיתכנות (BTC+ETH: edge חלש אך אמיתי)

---

## מה v0.1 הוכיח

| ממצא | משמעות |
|------|--------|
| Lift חיובי על BTC+ETH | יש מבנה אטומי, לא רעש טהור |
| p-value ~0.05 (BTC), ~0.01 (ETH) | סטטיסטית על הגבול–בינוני |
| 15–26 stable rules | מעט חוקים שורדים — טוב לאנטי-אוברפיט |
| Calibration משתפר בין ריצות | מנגנון % עובד, צריך עוד נתונים |
| Significant changes מזוהים | תשתית ל"מתי משהו קרה" קיימת |

**מסקנה:** היתכנות מאושרת. v0.2 = לחזק, לחבר, להרחיב — לא להתחיל מחדש.

---

## עקרונות v0.2 (נשארים)

1. **בלי deep learning** — rule accumulation + calibration + statistics
2. **בלי APIs חיצוניים** בשלב זה (חדשות = v0.3+)
3. **Walk-forward בלבד** — אין random split
4. **מינימום חישוב** — cache, vectorized, incremental
5. **כל שינוי חייב מבחן היתכנות** — shuffle + segments לפני קידום
